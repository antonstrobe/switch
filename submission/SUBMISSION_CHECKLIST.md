# Gemma 4 Good Hackathon Checklist

Deadline: 18 May 2026, 23:59 UTC.

## Required

- Kaggle report: max 1500 words.
- Public YouTube video: max 3 minutes, no login required.
- Public code repository: GitHub or Kaggle Notebook, no login or paid access.
- Public live demo URL or downloadable demo files.
- Media gallery cover image.

## Project Positioning

- Track: Impact Track, Safety and Trust.
- Problem: private local visual monitoring for homes, classrooms, workshops and remote facilities.
- Gemma 4 use: official `google/gemma-4-E2B-it` multimodal image-text understanding.
- Competition files: `kagglehub.competition_download("gemma-4-good-hackathon")`.
- Technical proof: local desktop app, capture pipeline, official model runtime, Redis visual memory, tests.

## Video Structure

1. Problem: privacy-sensitive spaces need visual assistance without cloud dependence.
2. Demo: start monitoring, show live frame, show Gemma answer.
3. Memory: search for an object or risk in prior observations.
4. Trust: show local storage, thumbnails, no face identity claims.
5. Impact: education, safety, elder care, small clinics, workshops.

## Before Submission

- Make the GitHub repository public.
- Replace or remove outdated private release binaries.
- Attach demo files or a public demo link.
- Add a cover image to Kaggle media gallery.
- Confirm the report links to the public repository and demo.
